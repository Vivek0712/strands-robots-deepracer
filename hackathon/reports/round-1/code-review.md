Not findings (checked and passed):

- `on_error` is a property returning `"deny"` on `MotionGate`, `FrameGate` and `DeciderGate`; the registry honours it (`registry.py:250-257`) and the production test `test_handler_exception_is_deny_via_on_error` proves it.
- `Guide` on `before_tool_call` sets `event.cancel_tool = "GUIDANCE: ..."` (`registry.py:142-144`): the tool does not run. No `Transform` leaves the envelope unexamined (`gate.py:629-635` only halves `linear` after the envelope stage ran).
- Constructor signatures match the installed package: `Proceed(reason=None)`, `Deny(reason="")`, `Guide(feedback="", reason=None)`, `Confirm(prompt="", reason=None, response=None, evaluate=default_evaluate)` (`actions.py:44-101`). `before_tool_call(self, event, **kwargs)` may be sync or async (`handler.py:51-56`).
- Threshold edges: `inside == YES` -> Proceed, `inside == NO` -> Confirm, person `== 0.5` -> Deny, `unclear == 0.65` -> Deny, `unclear == 0.6499` -> Proceed, `combine_frame_answers(0.5, "clear", 0.9, 0.5) == ("person_in_frame", 0.5, ...)`, `combine_frame_answers(0.4, "person_in_frame", 0.3, 0.5)` keeps the five-way: monotone toward Deny.
- Thresholds are named (`YES`, `PERSON_THRESHOLD`, `UNCLEAR_THRESHOLD`, `deny_threshold`, `unclear_threshold`) with the policy-knob comment; `DEEPRACER_UNCLEAR_THRESHOLD` is parsed with `float()` (an unparseable value raises at construction, which is acceptable).
- No frame, empty frame, camera exception, half an answer (`ask_frame`), timeout, HTTP 500, non-JSON body, missing `answers`, missing a named answer: all Deny in production (`test_gate.py`, `test_decider_client.py`) and in the patterns (`test_patterns.py` refusal tables).
- Approval timeout returns `Confirm(response=False)` and logs `approval {decision: timeout}` (`gate.py:650-656`).
- `Decider.ask` posts `{"state", "model", "questions"}` to `/v1/systemone`, adds `images` only when given, returns `payload["answers"]` (`_client.py:148-169`; `test_client_ask_request_body_shape`).
- Tests use `monkeypatch`ed `urlopen` and `httpx.MockTransport`; no sockets to real servers.
- `_client.py` has no `except Exception` and no default probability. `gate.py:690` `except Exception` denies (fail-closed by design) and logs.
